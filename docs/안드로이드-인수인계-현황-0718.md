## 2. ⚠️ 안드 빌드 전 결정 필요: 광고 맞춤/비맞춤

iOS 리젝 대응으로 `App.js`의 전면광고가 **전 플랫폼 비맞춤(NPA)** 으로 바뀌었다:

```js
const ad = InterstitialAd.createForAdRequest(AD_UNIT_INTERSTITIAL, { requestNonPersonalizedAdsOnly: true });
```

- 안드로이드는 ATT가 없으므로 **맞춤 광고를 켜도 무방** (eCPM 더 높음, 한국 타깃이면 GDPR 동의 플로우 불필요)
- 안드 AAB 빌드 전에 원하면 아래처럼 플랫폼 분기로 바꿀 것 (또는 그대로 NPA 유지해도 동작엔 문제 없음):

```js
{ requestNonPersonalizedAdsOnly: Platform.OS === 'ios' }
```

- IAP 상품 ID·가격은 **iOS ASC에 이미 등록된 것과 동일하게** 맞출 것 (코드가 같은 ID를 사용)
